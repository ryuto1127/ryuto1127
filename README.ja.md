### こんにちは、Ryutoです 👋

私は自然言語でAIコーディングエージェント（主にClaude Code）を動かしながら、本番運用に耐える品質のソフトウェアを作っています。コードを1行ずつ書く代わりに、自然言語でプロジェクトを理解し、設計判断についてAIと対話を重ねる。その結果、AI単独では届かない品質と、人間単独では出せない速度の両立を狙っています。

#### 仕事の進め方

AIを「使う」のではなく、AIと「組む」スタイルです：

- **対話でAIの天井を超える** — 単発生成は「動くが浅い」で頭打ちになる。「なぜこの設計？」と問い続けて、理由のある構造まで持っていく。
- **どちらか一方では出せない速度** — waysteは2週間、steadiiは1週間。どちらも本番運用に耐える品質（適切な認証、決済処理の安全性、網羅的なテスト）で作っている。応急処置のMVPではない。
- **主張ではなく検証で示す** — 両プロジェクトとも自動セキュリティレビューを通している。AI駆動開発であることと、安全であることは両立する。
