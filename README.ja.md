### こんにちは、Ryutoです 👋

私はAIコーディングエージェント（主にClaude Code）と対話しながら、本番で動かせる品質のソフトウェアを作っています。コードを1行ずつ書くのではなく、プロジェクトの内容を自然言語で理解し、設計判断についてAIと議論を重ねる。その結果、AI単独では届かない品質と、人間単独では出せない速度を、同時に実現することを目指しています。

#### 作ったもの

🗑️ **[wayste](https://github.com/ryuto1127/wayste)** — リアルタイムでゴミの分別を判定するAIキオスク。ブラウザ内で動くYOLO（自作の15クラスモデル、ONNX Runtime Web）が大半の品物をその場で判定し、学習させていない珍しい品物だけGPT-5.4 miniに送る構成。**作ったのは2週間。現在、日本国内の複数のオフィスと空港運営会社1社と実証実験の話を進めています。** [デモを見る →](https://wayste.vercel.app/)

📚 **[steadii](https://github.com/ryuto1127/steadii)** — 大学生向けの「先回り型」AIエージェント。Gmail、Googleカレンダー、シラバス、間違いノートを横断して読み込み、必要な返信は下書きまで用意し、予定のかぶり（旅行と試験の重なり、出張中の締切、対策が間に合わない試験など）をユーザーが気づく前に検知します。判断の根拠はすべて可視化されている（ガラス箱の推論）。送信は20秒のキャンセル時間つき。L1ルール + L2 LLM の二段階で振り分ける構成です。**作ったのは1週間。現在、日本の大学生10名を招いた招待制α版で運用中。北米向け一般公開は2026年8〜9月予定。** [使ってみる →](https://mysteadii.xyz/)

#### 仕事の進め方

AIを「使う」のではなく、AIと「組む」感覚で進めています：

- **対話を重ねてAIの上限を突破する** — AIに1回で書かせると「動くが浅い」で止まる。「なぜこの設計？」を問い続けて、理由のある構造まで持っていく。
- **片方だけでは出せない速度** — waysteは2週間、steadiiは1週間。どちらも本番で動かせる品質（適切な認証、安全な決済処理、網羅的なテスト）で作っている。MVPレベルではない。
- **主張するだけでなく検証する** — 両プロジェクトとも自動セキュリティレビューを通しています。AI駆動開発と安全性は両立できる、ということを実物で示したい。
