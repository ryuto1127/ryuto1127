### こんにちは、Ryutoです 👋

自分自身が本当に必要だと感じる課題を出発点に、AIネイティブなプロダクトを作っています。現在の関心は、人間の判断とAIエージェントの境界です。曖昧な現実の課題を、明確な制約のもとで推論し、行動し、改善できるシステムに落とし込むことに強い関心があります。

開発では Claude Code などのAIコーディングエージェントを活用していますが、AIをブラックボックスとして扱っているわけではありません。私が責任を持っているのは、課題設定、プロダクト方針、設計議論、システムや挙動レベルでの実装レビュー、テスト、デバッグ、デプロイ、改善です。AIは実装速度を大きく上げてくれますが、そのプロダクトが本当に役に立つか、信頼できるか、作る価値があるかを決める判断は自分で持つようにしています。

#### 仕事の進め方

- **現実の制約から始める** — 自分が実際に見た不便や違和感を出発点に、プロダクトが存在する理由が明確になるまで課題を絞り込みます。
- **曖昧なアイデアを技術要件に変換する** — 実装前に、ユーザーフロー、期待するシステムの挙動、データの境界、失敗パターン、プロダクトが証明すべきことを整理します。
- **AIで速く作るが、理解を放棄しない** — AIエージェントで実装速度を上げつつ、設計判断を問い直し、挙動を検証し、失敗をデバッグし、実際の動作を見ながら改善します。
- **人間の判断が必要な部分を持ち続ける** — AIは選択肢を高速に出せますが、何を作るべきか、どのトレードオフを受け入れるか、結果が本当にユーザーのためになっているかは自分で判断します。

#### 現在の技術的な関心

- Webプロダクト: 認証、API設計、デプロイ、データ設計、プライバシー、セキュリティ基礎
- コンピューターサイエンス基礎: データ構造、アルゴリズム、システム思考、デバッグ
