### こんにちは、Ryutoです 👋

私はAIコーディングエージェント（主にClaude Code）と対話しながら、本番でちゃんと使えるソフトウェアを作っています。コードは自分で1行ずつ書きません。代わりに、プロジェクトの中身を言葉で理解し、設計の判断についてAIと何度も議論を重ねる。その結果、AI一人では届かない品質と、人間一人では出せないスピードを、同時に実現することを目指しています。

#### 作ったもの

🗑️ **[wayste](https://github.com/ryuto1127/wayste)** — リアルタイムでゴミの分別を教えてくれるAIキオスク。ブラウザの中で動くYOLOというAIモデル（自作の15クラス版、ONNX Runtime Web経由）がほとんどの品物をその場で判定し、学習させていない珍しい品物だけGPT-5.4 miniに送って判定します。**作ったのは2週間。いま日本国内の複数のオフィスと、空港の運営会社1社と、実証実験の話を進めているところです。** [デモを見る →](https://wayste.vercel.app/)

📚 **[steadii](https://github.com/ryuto1127/steadii)** — 大学生のための「先回りして動く」AIアシスタント。Gmail、Googleカレンダー、授業のシラバス、自分の間違いノートをまとめて読み込み、必要な返信は下書きまで用意し、予定のかぶり（旅行と試験の重なり、出張中の締切、勉強の間に合わない試験など）をユーザーが気づく前に見つけてくれます。AIがどう判断したかは、すべて見えるように作られています（ガラス箱の推論）。送信は必ず20秒のキャンセル時間つき。**作ったのは1週間。いま日本の大学生10名を招待した非公開α版で動かしているところ。北米向けの一般公開は2026年8〜9月の予定です。** [使ってみる →](https://mysteadii.xyz/)

#### 仕事の進め方

AIを「使う」のではなく、AIと「組む」感覚でやっています：

- **対話を重ねてAIの上限を突破する** — AIに1回で書かせると「動くけど浅い」で止まります。「なぜこの設計？」と聞き続けて、ちゃんと理由のある作りに持っていく。
- **片方だけでは無理なスピードを出す** — waysteは2週間、steadiiは1週間。どちらも本番で使える品質（ちゃんとした認証、安全な決済処理、網羅的なテスト）で作っています。やっつけのデモではありません。
- **言うだけでなく、ちゃんと確かめる** — 両方のプロジェクトとも、自動セキュリティレビューを通しています。AIで作ってもちゃんと安全にできる、ということを実物で示したい。
